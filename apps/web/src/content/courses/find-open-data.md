Open AI starts with open data you can inspect. This module teaches you to find it and trust it.

## Why an index beats a mirror

Re-hosting data multiplies custody risk. Unite4AI indexes datasets with consent, PII review, and bias notes — then links out to where the data actually lives.

## Steps

1. Browse [/registry/datasets](/registry/datasets)
2. Read the ethics panel on any card
3. Follow the storage protocol link (HTTPS, IPFS, Hugging Face, Git)
4. Verify checksums when provided

## Exercise

Pick one dataset and write down: who consented, what's under-represented, and where the authoritative copy lives.
