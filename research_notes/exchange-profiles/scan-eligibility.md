# Automated-scanning eligibility: 20 Global Exchange projects

Researched by the `ScanEligibility` scout agent (omp harness, model claude-opus-5-5) for Task 10 Step 7 of `docs/superpowers/plans/2026-11-22-exchange-profiles.md`. Not yet reviewed by the owner.

Retrieval date for every quote and URL: **2026-11-22**. All research was passive and public only: no sign-ups, no log-ins, no submissions, no contact, no testing.

**Evidence standard used:** a project is "eligible" only if programme text, quoted word for word, explicitly permits automated scanning or testing of named web assets. If the text is silent, ambiguous, or prohibits it, the project is not eligible. Smart-contract-only scopes are not eligible for web scanning.
